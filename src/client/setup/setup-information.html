Application Roles

Assign roles based on how users interact with Identity Verification.

x_entru_entrustidv.admin
Configure and administer the Identity Verification application.
x_entru_entrustidv.agent
Initiate identity verification from supported ServiceNow records.

Email

Enable outbound email in ServiceNow so verification links can be delivered to users.

ServiceNow navigation
All → System Properties → Email Properties → Outbound Email Configuration
